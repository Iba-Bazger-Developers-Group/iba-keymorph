# Фирменный стиль IBA KeyMorph

Основа — брендбук IBA, редакция 4.2 (`IBA_Brandbook_Complete.pdf`), и панда IBA. PDF главнее любых
образцов: значения цветов взяты из него (синий `#0055FD`, не `#0055FF`).

## Палитра (брендбук, стр. 58)

| Роль | Цвет | Где |
|---|---|---|
| IBA Blue | `#0055FD` | единственное главное действие, выбранная вкладка, переключатель «вкл», ссылки, выделение в списках и в меню |
| Blue (нажатие/наведение) | `#0046D0` | тот же синий, темнее; подписи-заголовки секций (мелкий текст — синим, не оранжевым) |
| Ink | `#101421` | основной текст, кольцо клавиатурного фокуса, буквы на оранжевом |
| Mist | `#F0F3FA` | фон окон |
| Белый | `#FFFFFF` | карточки, поля, меню |
| Orange | `#FFA500` | редкий акцент: точка после названия («IBA KeyMorph•», как точка логотипа), значок трея RU |
| Вторичный текст | `#546078` | 6,4:1 на белом, 5,7:1 на Mist |
| Границы | `#D6DEEE` / `#96A2BC` | карточки / выключенный переключатель, рамка чекбокса |
| Успех | `#15784F` | точка «Работает» (всегда вместе со словом) |
| Предупреждение | `#9A5B00` | текст проблем, всегда со словом и «⚠︎» |

Контраст: белый на Blue 5,6:1, Ink на белом 18,4:1, Ink на оранжевом 9,3:1. Цвет не несёт смысл
один: состояния — слово + точка, переключатели различаются положением, раскладки в трее — буквами.

## Шрифты

Целевое семейство — **Manrope** (брендбук, стр. 59). Manrope Regular и Bold (статические
инстансы из Manrope Variable, лицензия SIL OFL — `assets/fonts/OFL.txt`) встроены:

- Windows: файлы лежат ресурсами в `IbaKeyMorph.exe`, `Theme` регистрирует их для процесса
  (`AddFontMemResourceEx`) и проверяет, что семейство найдено; иначе — Segoe UI (системный
  резерв по брендбуку).
- macOS: `build-app.sh` кладёт их в `Contents/Resources`, `IBA.hasManrope` регистрирует их
  (`CTFontManagerRegisterFontsForURL`); иначе — системный шрифт.

Журнал/исключения — моноширинный (Consolas / системный monospaced), как «код» в брендбуке.

## Компоненты

- Карточки: белые, граница 1 px, радиус 10–12.
- Кнопки: высота 40, радиус 10, подпись действия; главная — Blue с белым текстом, остальные — белые с
  границей; нажатие/наведение, недоступность и **видимый фокус** (кольцо Ink 2 px) есть у всех.
- Переключатели: включён — Blue, выключен — серо-синий; фокус — кольцо Ink.
- Списки: выбранная строка — Blue с белым текстом.
- Пустые состояния (брендбук: объяснять состояния): пустой список исключений слов и программ,
  пустой выбор программ и «ничего не найдено» — сообщение, что пусто и что делать.
- Меню в трее/строке меню — системное; в Windows перекрашено (белый фон, Ink, выделение Blue).
- Названия: «IBA KeyMorph — переключатель раскладки клавиатуры» (брендбук, стр. 15); IBA — заглавными.

## Иконки и картинки

**Иконка приложения — общий синий знак IBA с глобусом и орбитой, один у всех приложений IBA** (решение владельца;
как у Accounting и CRM). Мастер — `assets/brand/iba-app-icon-1024.png` (копия
`IBA_Accounting/assets/brand/app-icon-1024.png`); не перерисовывается, только масштабируется и кадрируется.
**Панда остаётся внутри приложения** (шапка настроек, «О программе», баннер установщика).

| Файл | Из чего / чем |
|---|---|
| `assets/icon-1024.png` | мастер иконки, без изменений |
| `assets/keymorph.ico` | `make-icons.ps1 -Ico` (16, 24, 32, 48, 64, 128, 256 — как у Accounting): значок exe, окон и установщика |
| `assets/icon-macos-1024.png` | `make-assets.py`: мастер в плитке macOS (824 px, скруглённый квадрат на 1024) → `AppIcon.icns` в `build-app.sh` (16–512 и @2x) |
| `assets/menu-glyph.png` | `make-assets.py`: монохромный глиф «глобус + орбита» (44×22, чёрный с альфой), вырезан из мастера, без текста; в строке меню macOS — template-изображение (`isTemplate`), macOS красит его под тему |
| `assets/panda-logo.png` | `make-icons.ps1 -Resize` из панды `iba-icon-jade-1024.png`, 512 px: шапка настроек и «О программе» (углы скругляются в коде) |
| `assets/installer/*.bmp` | `make-assets.py`: баннер из `panda-jade-staff-sky-1254.png` + «IBA KeyMorph•»; малый значок — иконка приложения |

**Строка меню macOS:** глиф (template) слева + текущая раскладка текстом `EN`/`RU` (функция программы, системный цвет).
**Трей Windows:** показывает текущую раскладку, поэтому остаётся значком с буквами (EN — синий, RU — оранжевый с Ink-буквами,
прочие — Ink, выключено — серый), а не картинкой: глиф размером 16 px не различает раскладки, а цвет без буквы не
несёт смысла (брендбук, стр. 78). Иконка приложения (`keymorph.ico`) видна в окнах, «Пуске», установщике.

```powershell
# Windows .ico (из корня репозитория) и панда для окон
powershell -File C:\MyFiles\iba-branding\make-icons.ps1 -Source assets\brand\iba-app-icon-1024.png -Ico assets\keymorph.ico
powershell -File C:\MyFiles\iba-branding\make-icons.ps1 -Source assets\brand\iba-icon-jade-1024.png -Resize assets\panda-logo.png
python assets\make-assets.py     # icon-1024.png, icon-macos-1024.png, menu-glyph.png, installer\*.bmp (нужен Pillow)
```

Как заменяются иконки у пользователей (ярлыки, кеш значков, старые копии на Mac) — `docs/ICON-UPDATE.md`.

## Проверка интерфейса без экрана

`IbaKeyMorph.exe --render-ui <папка>` (Windows) и `IBAKeyMorph --render-ui <папка>` (macOS) пишут
PNG окон: настройки (3 вкладки), пустые списки, «О программе»/выбор программ, значки трея (Windows).
