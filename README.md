# IBA KeyMorph

[![CI](https://github.com/Iba-Bazger-Developers-Group/iba-keymorph/actions/workflows/ci.yml/badge.svg)](https://github.com/Iba-Bazger-Developers-Group/iba-keymorph/actions/workflows/ci.yml)

Автоматический переключатель раскладки клавиатуры для **Windows** и **macOS**, аналог Punto Switcher.

**[⬇ Скачать последнюю версию](https://github.com/Iba-Bazger-Developers-Group/iba-keymorph/releases/latest)**

Набрали `ghbdtn` вместо «привет» или `руддщ` вместо «hello»? IBA KeyMorph заметит это в момент
нажатия пробела, сотрёт слово, напечатает его в правильной раскладке и переключит раскладку, чтобы
дальше вы печатали без ошибок.

## Возможности

- **Автоисправление раскладки EN ⇄ RU** на границе слова (пробел, Enter, Tab), с сохранением регистра
  и знаков препинания: `Ghbdtn? rfr ltkf&` → `Привет, как дела?`.
- **Исправление короткого слова перед исправленным**: `z ns` → `я ты`.
- **Отмена и обучение**: если исправление было ошибочным, нажмите горячую клавишу сразу после
  него — слово вернётся и попадёт в список исключений.
- **Ручная конвертация** текущего/последнего слова и **выделенного текста** (буфер обмена
  сохраняется и восстанавливается).
- **Исправление случайного Caps Lock**: `пРИВЕТ` → `Привет`, Caps Lock выключается.
- **Исключения**: список слов и список программ (терминалы, менеджеры паролей, удалённый рабочий стол),
  в которых автоисправление отключено.
- Не вмешивается в поля паролей, защищённый ввод macOS и окна, запущенные от администратора (Windows).
- Индикатор текущей раскладки в трее (Windows) или в строке меню (macOS), звук при переключении,
  автозапуск.
- **Приватность**: всё работает локально, без сети. Нажатия не сохраняются; в памяти хранится только
  текущее и предыдущее слово.

## Горячие клавиши

| Действие                                        | Windows                    | macOS         |
|-------------------------------------------------|----------------------------|---------------|
| Исправить последнее слово / отменить исправление | `Pause` или `Shift` `Shift` | `⇧` `⇧`       |
| Исправить выделенный текст                      | `Shift+Pause`              | `⌥` `⌥`       |
| Настройки                                       | двойной щелчок по значку    | меню → «Настройки…» |

`Shift` `Shift` и `⌥` `⌥` — два быстрых нажатия клавиши без других клавиш между ними.

## Установка

Готовые сборки создаёт GitHub Actions (вкладка **Actions** → артефакты, или **Releases** для тегов `v*`).

### Windows 10/11

- `IbaKeyMorph-<версия>-x64-setup.exe` — установщик для текущего пользователя (права администратора
  не нужны), с ярлыком в меню «Пуск» и автозапуском.
- `IbaKeyMorph-<версия>-win-x64-portable.exe` — портативная версия одним файлом (.NET встроен).
- Для ARM-ноутбуков — сборки `arm64`.

Настройки хранятся в `%APPDATA%\IBA\KeyMorph\settings.json`, журнал ошибок — `keymorph.log` там же.

### macOS 13+

1. Распакуйте `IBA-KeyMorph-<версия>-macOS.zip` и перенесите `IBA KeyMorph.app` в «Программы».
2. Первый запуск: правый щелчок → «Открыть» (сборка CI подписана ad-hoc, без нотаризации Apple).
3. Разрешите доступ: **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**
   → включите IBA KeyMorph. Приложение подхватит разрешение само.

Для распространения внутри компании соберите приложение с сертификатом Developer ID:
`CODESIGN_IDENTITY="Developer ID Application: …" ./macos/build-app.sh` и нотаризуйте его через
`xcrun notarytool`. После каждой пересборки с ad-hoc подписью macOS заново спрашивает разрешение.

## Как это работает

```
нажатие клавиши ──► перехват (WH_KEYBOARD_LL / CGEventTap)
                      │  физическая клавиша + Shift/Caps
                      ▼
                TypingEngine (общий для обеих ОС)
                      │  на пробеле/Enter/Tab: как выглядело бы слово в каждой раскладке?
                      ▼
                LayoutDecider ── словарь EN/RU + триграммная модель языка
                      │  «исправить?»
                      ▼
   Backspace × N, печать Unicode-текста, повтор пробела, переключение раскладки
```

1. Приложение запоминает **физические клавиши** текущего слова. Символы для любой установленной
   раскладки получаются через API ОС (`ToUnicodeEx` в Windows, `UCKeyTranslate` в macOS), поэтому
   поддерживаются и «Русская – ПК», и обычная «Русская» раскладка Mac, и любые другие варианты.
2. На границе слова `LayoutDecider` сравнивает набранный текст и его вариант в другой раскладке:
   - набранное слово есть в словаре → оставить;
   - вариант в другой раскладке есть в словаре → исправить (от 2 букв);
   - иначе решает **триграммная модель** языка, обученная на словарях: вариант должен быть заметно
     правдоподобнее (на 1.0 по среднему логарифму вероятности), а набранное — похоже на бессмыслицу.
3. Пороги подобраны на тестовых наборах (`data/tests`). Результат на словах, которых нет в словаре:
   **0 ложных исправлений**, ~90 % исправлений для слов, набранных не в той раскладке; для словарных
   слов — ~99.7 %.

Логика ядра одинакова в C# (`windows/IbaKeyMorph.Core`) и Swift (`macos/Sources/KeyMorphCore`).
Совпадение проверяется тестами по эталонным значениям `data/tests/golden-scores.tsv`.

## Словари

`data/en.txt` и `data/ru.txt` — списки слов (через пробел, `#` — комментарий). Чтобы улучшить
распознавание, добавляйте частые слова и их формы. После изменения словарей:

```bash
cd windows && IBA_REGENERATE_GOLDEN=1 dotnet test IbaKeyMorph.Core.Tests   # обновить эталон
dotnet test IbaKeyMorph.Core.Tests && (cd ../macos && swift test)          # проверить обе реализации
```

Тест `NoDictionaryWordLooksLikeAnotherDictionaryWordUnlessListed` сообщит, если новое слово совпадает
по клавишам со словом другого языка (как `in` / `шт`). Такие пары не исправляются ни в одну сторону.

## Сборка из исходников

**Windows** (.NET 8 SDK):

```powershell
dotnet test windows/IbaKeyMorph.Core.Tests
dotnet run --project windows/IbaKeyMorph
dotnet publish windows/IbaKeyMorph -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
```

**macOS** (Xcode 15+ / Swift 5.9+):

```bash
cd macos
swift test
./build-app.sh            # build/IBA KeyMorph.app и zip
```

```

  Tests/                  XCTest

```

## Ограничения

- Поддерживаются языки EN и RU; другие раскладки (например, украинская) переключаются вручную горячей
  клавишей, для автоисправления нужен словарь и модель языка.
- Windows: в окна, запущенные от имени администратора, синтетический ввод не доходит, поэтому
  KeyMorph их пропускает (если нужно, запустите KeyMorph от администратора).
- Конвертация выделения использует копирование и вставку: в редакторах, которые копируют всю строку
  при пустом выделении, сначала выделите текст.
- Методы ввода с составными символами (японский, китайский) и мёртвые клавиши не отслеживаются.
