# Гайд IBA KeyMorph для store.ibateam.org — что куда положить

Материал подготовлен в формате гайдов портала (`gridcraft_distribution`, ветка `feature/seo-store`:
`seo.py`, `docs/SEO.md`). Портал не менялся и не деплоился. Проверено разбором тем же `seo.py`
(`parse_guide`, лимиты из `tests/test_seo.py`) и локальным рендером страницы `guide_page()` в трёх языках.

только на русском, это сказано в подписях).

## Правки портала, без которых картинки не заработают

1. **`portal.py`, `ASSETS`**: добавить имена файлов — иначе `/keymorph-*.png` отдаст 404 (раздаются только
   перечисленные имена; MIME для `.png` уже есть):
   `'keymorph-settings-general.png', 'keymorph-settings-exceptions.png', 'keymorph-settings-programs.png',
   'keymorph-app-picker.png', 'keymorph-about.png', 'keymorph-tray-menu.png', 'keymorph-tray-icons.png'`.
   Если интеграция других гайдов вводит папку для картинок гайдов, достаточно сменить путь в `src="/…"`
   (поиск-замена по трём файлам).
2. **`static/guides.css`**: дописать `guides-figures.css` — стили `figure.g-figure`, подписей, `kbd`, `code`
   (в текущем CSS их нет; без этого картинки не ужимаются по ширине экрана и клавиши не выделены).
3. **`tests/test_seo.py`**: ничего менять не нужно; но `test_orders_are_unique…` требует уникальный `order`.
   У гайда `order: 26`; другие гайды из этой серии могут взять те же числа — при сборке шести гайдов
   проверить уникальность и при необходимости переименовать (`order` одинаков в трёх языках).

## Что стоит решить при интеграции

- **CTA «Скачать IBA com».** Портал вставляет в каждую статью блок про IBA com (кнопка «Скачать IBA com» и
  ссылка Google Play). Для гайда про KeyMorph это не по теме. Нужен либо необязательный ключ шапки
  (например `product: keymorph`) и свой текст/ссылка `/?lang=…#apps`, либо нейтральный CTA «Все программы
  IBA». В тексте гайда ссылки на магазин даны через `href="store:"`.
- **Главная страница магазина** показывает четыре гайда с наименьшим `order`. Если KeyMorph должен быть
  среди них — поставить `order` меньше.
- **Картинки в JSON-LD.** У `Article` в разметке стоит общая картинка Open Graph. При желании сделать
  первой картинкой гайда `keymorph-settings-general.png` (нужен ключ шапки `image`).
- **Имена файлов в тексте.** Гайд говорит «файл `…-setup.exe`» и «портативная версия одним файлом» — это
  имена из GitHub Releases (`IbaKeyMorph-<версия>-x64-setup.exe`). Проверить, как файлы названы в самом
  магазине (раздел desktop-программ), и поправить, если иначе.
- **Версия.** На скриншоте «О программе» версия 1.0.3 (опубликованная сейчас). Если к моменту выкладки
  выйдет другая, скриншот нужно переснять (`IbaKeyMorph.exe --render-ui <папка> ` из сборки с
  `-p:Version=…`) или оставить как пример.
- **Правило «без обхода блокировок».** Тексты проверены на слова из `test_articles_promise_no_way_around_blocking`.

## Приватность скриншотов

Все картинки сняты не с экрана, а встроенным режимом `--render-ui` (программа сама рисует свои окна в PNG),
поэтому на них нет рабочего стола, имён пользователя, путей, чужих программ. Список «Добавить программы»
на снимке — фиксированный пример (Блокнот, Paint, Проводник, Калькулятор, Windows Terminal), а не реальные
процессы компьютера. Список «Программы» — стандартный список исключений по умолчанию, счётчики нулевые.
Замазывать ничего не потребовалось. Значки трея и меню нарисованы тем же кодом программы.

## Картинки для Mac

Сняты на Mac встроенным режимом `IBAKeyMorph --render-ui` из нотаризованной сборки 1.0.4 (никаких снимков
экрана Mac): `keymorph-mac-settings-general.png`, `-exceptions.png` (пустой список), `-programs.png`,
`keymorph-mac-no-access.png`. Числа «нажатий 128 · исправлено 7» на снимках — демонстрационные значения
режима `--render-ui`, в подписях помечены как пример. Окно «Добавить из запущенных…» **не использовано**: оно
показывает реальные открытые программы Mac (там есть чужие и личные приложения). В тексты гайда вставлены
два снимка Mac (нет доступа, основные настройки); `-exceptions` и `-programs` лежат про запас.

Всё ещё нужно с Mac (режим `--render-ui` их не рисует, делать вручную, с чистой учётной записью):
меню в строке меню, окно «О программе» (системный `NSAlert`), системное «Универсальный доступ» и
«Всё равно открыть».
